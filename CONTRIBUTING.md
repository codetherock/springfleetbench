# Contributing

Thanks for helping make SpringFleetBench useful and reproducible.

- Keep the pilot deterministic and avoid network calls in unit tests.
- For repository fixtures, record the source revision and confirm its license permits redistribution.
- Add expected results and validation checks with every new task.
- Do not add production credentials, private source code, or generated build outputs.
- Report the Python version, operating system, suite revision, and candidate command when filing a bug.

Before proposing a novelty claim, update `docs/related-work.md` with close prior projects and explain the specific evaluation gap that remains.
